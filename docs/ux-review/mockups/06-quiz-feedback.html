If (A + B)(A − B) = A² − B² for square matrices A and B, what must be true?

A A = B
B A + B = 0
C AB = BA

Not quite

Expand it: (A + B)(A − B) = A² − AB + BA − B². That equals A² − B² only when BA − AB = 0, so A and B must commute: AB = BA.
