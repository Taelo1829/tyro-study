# 0008 AI providers only behind src/lib/ai

- **Status:** Accepted
- **Date:** 2026-10-29 (records the existing pattern)

## Context
AI writes lessons, questions, explanations, notes and marks code. Providers, models and prices change; AI replies can be malformed.

## Decision
All AI calls go through `src/lib/ai/*` (client from `getOpenAIClient()`, JSON through `chatJson()` with retries and validation, input cleaned with `cleanForAi()`). The model comes from `OPENAI_MODEL`. Prompts carry the UNISA/CAPS context from `lib/ai/unisa.ts`. AI output is generated by admins and stored; students never trigger AI on page views, and student-triggered marking is rate-limited.

## Consequences
Switching model or provider is a change in one folder. Costs stay predictable. Generated content still needs human review before students rely on it (backlog TS-025, TS-032).
