## Chapter-based quiz creation in admin

### Background / current state
- The data model **already supports** chapter quizzes: `Question.chapterId?` and `Chapter.questions Question[]` exist in `schema.prisma`.
- The existing student-facing chapter quiz at `src/app/(dashboard)/modules/[id]/chapters/[chapterId]/quiz/page.tsx` works, but it only surfaces questions attached to **topics** (`chapter.topics.flatMap(t => t.questions)`). It needs to also include questions attached directly to the **chapter**.
- The admin chapter page (`src/app/(dashboard)/admin/chapters/[id]/page.tsx` line 57) has a **"Preview quiz"** button to be replaced.
- **Bug to fix:** `/api/questions` POST always does `topic: { connect: { id: topicId } }` even when only `chapterId` is sent — so chapter-based creation is currently broken. Will fix to connect whichever of `topicId`/`chapterId` is provided.

### Plan

#### 1. Fix `/api/questions` POST route (`src/app/api/questions/route.ts`)
- Replace the hard-coded `topic: { connect: { id: topicId } }` with conditional connect logic: connect `topic` when `topicId` is present, connect `chapter` when `chapterId` is present. (The route already validates that at least one is present and that the referenced record exists.)

#### 2. Extend `/api/chapters/[id]` GET to include direct chapter questions
- Add `questions: { include: { answers: true }, orderBy: { createdAt: "asc" } }` to the Prisma include alongside the existing `topics` include, so the chapter detail payload exposes both topic-attached and chapter-attached questions.

#### 3. Update student chapter quiz page to include direct chapter questions
- In `src/app/(dashboard)/modules/[id]/chapters/[chapterId]/quiz/page.tsx`, extend the `Chapter` type and the `questions` `useMemo` to merge `chapter.questions` (direct) with `chapter.topics.flatMap(t => t.questions)`.

#### 4. Generalize the import route to accept chapterId (`src/app/api/questions/import/route.ts`)
- Accept either `topicId` or `chapterId` from the form data (validate at least one, validate the referenced record exists), and pass the correct id into `createQuestionsBatch` so the `Question.create` connects to the right parent. Keep `topicId` behavior unchanged when only `topicId` is provided.

#### 5. Generalize the ExcelBulkImport component (`src/components/admin/excel-import.tsx`)
- Rename/relax the prop from `topicId: string` to a parent pointer such as `{ topicId?: string; chapterId?: string }` (or `parentId` + `parentType`). Update the `formData.append` call to send whichever id is present. Update the topic admin page call site to pass `{ topicId }`.

#### 6. Build the chapter quiz creation UI
- Create `src/app/(dashboard)/admin/chapters/[id]/quiz/page.tsx` — a new admin page with three sections mirroring the topic admin page:
  - **Excel bulk import** (using the generalized component, passing `chapterId`)
  - **Manual question entry form** — a simple form (question text + 4 option inputs + radio for correct answer + difficulty select) that POSTs to `/api/questions` with `chapterId`. This is a small new form component (e.g. `src/components/admin/manual-question-form.tsx`), reusable and generic so it could also serve topics later.
  - **AI extraction** — reuse the existing `QuestionExtractor` component, generalized to accept a `chapterId` prop (it already POSTs to `/api/questions`; just change the body key). For the source text, since chapters have no `content` field, the AI extraction trigger will live on this page and use any provided text/topic content if available — or we omit AI extraction if no content source exists. (See open question note below — I'll default to including manual + Excel, and wire AI extraction only if a text source is available on the chapter; otherwise leave it out to avoid a dead control.)
- Show a **"Saved questions"** list (chapter-attached) like the topic page.
- Back-link to `…/admin/chapters/[id]`.

#### 7. Replace the "Preview quiz" button on the admin chapter page
- In `src/app/(dashboard)/admin/chapters/[id]/page.tsx` line 57: replace the `Preview quiz` `<Link>`/`<Button>` with a **"Manage quiz"** (or "Create quiz") button linking to the new `/admin/chapters/[id]/quiz` page. Change the gating condition from "any topic has questions" to always-shown (since chapter questions can now exist independently) — or keep a count badge. Remove the now-unused `PlayCircle` import.

#### 8. Verify
- Run `npx tsc --noEmit` to confirm types pass.

### Open note (deciding sensibly without an answer)

I'll include **Excel bulk import + manual entry** for sure, and **skip AI extraction** at the chapter level unless chapter content is added elsewhere. This keeps the new page focused and avoids a control with no input source.
